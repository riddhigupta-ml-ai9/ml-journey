# ML Journey

My ongoing journey to learn machine learning properly and build things with it.
Notebooks, experiments and projects, added as I learn.
I'm a second-year Data Science undergraduate in Kolkata.

## What's inside

| Topic | Notebook | What it covers |
|---|---|---|
| NumPy | 01-foundations/numpy/01_tensors.ipynb | 0D, 1D and 2D tensors, ndim |
| pandas | 01-foundations/pandas/01_working_with_csv.ipynb | read_csv parameters (sep, usecols, encoding, etc.) |
| EDA | 02-data-preparation/eda/01_understanding_data_titanic.ipynb | Shape, info, missing values, duplicates, correlation |
| EDA | 02-data-preparation/eda/02_univariate_eda_titanic.ipynb | Countplots, histograms, boxplots, skewness |
| Preprocessing | 02-data-preparation/preprocessing/01_standard_scaler.ipynb | StandardScaler, effect of scaling |
| Classification | 03-supervised-learning/classification/01_logistic_regression_placement.ipynb | Scaling + Logistic Regression on a placement dataset |
